<h1> "Effects of Conditional Cash Transfers on School Dropout Rates: A Bayesian Approach to Modelling Linear Regression" </h1>

<h2>Description</h2>
This project showcases the application of Bayesian linear regression as a methodological framework, focusing on estimating the effects of a social program on school dropout rates. Emphasizing the modeling process, it implements non-informative priors to maintain objectivity and uses Gibbs Sampling to compute posterior distributions for model parameters. Prior and posterior predictive checks are conducted to validate both the priors and model fit. The analysis highlights the practical use of Bayesian techniques—particularly in setting priors, running MCMC, and evaluating posterior results—making it a clear example of Bayesian modeling in applied social data analysis.

Please find the report of the proyect attached as well as the script and slides summarizing the model implemented and results.
